# Grupo Empresarial CKD — presentación web

Presentación corporativa interactiva en español, adaptada a escritorio y móvil. HTML, CSS y JavaScript sin dependencias de compilación.

## Ejecutar

Desde este directorio:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

Abra el servidor en un navegador. Pulse la marca CKD para desplegar las 23 marcas, filtre por sector y seleccione una marca para ver sus servicios. El diálogo permite avanzar con los botones o las flechas del teclado; Escape lo cierra. El modo presentación activa la pantalla completa cuando el navegador lo permite.

## Contenido y recursos

Información y logotipos extraídos de la presentación corporativa suministrada. UNG utiliza una composición tipográfica provisional aprobada por el usuario. Los Toluqueños conserva su estado de proyecto y UNIDM su proceso de conversión. El salón comparte el logotipo de Gran Cardenal. Las variantes de nombres se conservan según el documento fuente.

Las fuentes de Google son opcionales: hay fuentes locales de respaldo. No requiere claves, backend ni servicios externos. Para publicar, cualquier alojamiento de sitios estáticos puede servir estos archivos. No se ha realizado un despliegue remoto.
